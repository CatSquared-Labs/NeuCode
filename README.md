# NeuCode

## About

NeuCode is a simple and lightweight IDE made in neutralino.js.

## Preview


![preview](https://github.com/user-attachments/assets/5f449076-eb79-4e04-a747-07f0bffd32ea)


## Why NeuCode

NeuCode is an open source lightweight IDE that is PERFECT for uses like: developing C software, developing python software, developing websites and web apps, etc. And it has support for languages that other IDEs don't!
